# hidroponia-raspberry
Proyecto de creacion de una hidroponia con sensores usando raspberry pi

Sensores:
- Temperatura del agua (SI)
- Bomba de agua (SI)
- Conductividad / Calidad del agua (SI)
- Servomotor (SI)
- Nivel del agua (NO)

Comando para conectarse a raspberry: ssh pi@ip_address
